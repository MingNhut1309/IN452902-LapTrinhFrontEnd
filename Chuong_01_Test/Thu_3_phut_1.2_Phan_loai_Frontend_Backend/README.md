# Thử ngay 1.2 — Phân loại Frontend và Backend

1. **Frontend** — hiển thị bảng lịch sự kiện trên trình duyệt.
2. **Backend** — lưu thông tin sinh viên vào cơ sở dữ liệu trên máy chủ.
3. **Frontend** — HTML có thể kiểm tra MSSV bằng `pattern="[0-9]{10}"`; Backend vẫn cần kiểm tra lại dữ liệu.
4. **Backend** — máy chủ kiểm tra email đã tồn tại trong cơ sở dữ liệu hay chưa.
5. **Frontend** — thẻ `<details>` cho phép mở và đóng câu trả lời ngay trên trang.
